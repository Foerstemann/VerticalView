Two scritps for the R! programming environment are provided. Do you have one or a few proteins of interest and want to find out more about how different parts of the sequence have fared during evolution? In particular, do you want to know if perhaps a more abstract biophysical property has been conserved in a sub-region, while the primray amino acid sequence has not? You may find  VerticalView useful.
The first script conducts a BLAST serach to identify homologues of your query protein in the RefSeq database. Only one sequence per species is kept to avoid overrepresentation of the more thoroughly studies critters. The second script then takes the ensemble of homologues, generates a multiple sequence alignment and segments each protein sequence accordingly into sections that are either conserved (= consensus sequence can be established) or not. For each section, a small selection of biophysical parameters and aminoacid as well as dipeptide sequences are calculated. The plots then serve to guide your interpretation as to whether one of the properties has been maintained and may thus be of functional relevance.
In some ways, this is akin to searching an abstract „flavor“ that emerges from the ensemble of amino acids in a sequence section, then trying to follow the scent over time into the past. It is reminiscent of wine tasting: A „vertical“ is a rare treat that examines the same wine but from different vintages (usually progressing from recent years to the older bottles). Hence, the two scripts provide a „vertial“ view of your query protein. 
Just as with wine, moderation is essential here. The first script uses the NCBI BLAST web server API for the homology search. This is a resource shared with many and strict limitations are applied; it is also not particularly fast. VerticalView is thus for one or a few query sequences at a time, not for „omics“ motivated analyses.
